# Contributors

This repository starts from a single commit. The plugin was rewritten in 2026 against a Domotz
codebase that had been developed internally since 2025, and the public history begins with that
rewrite rather than carrying the internal one across.

The earlier version — the query editor, the API client and the first working data source — was
built by:

- Andrea Azzarà
- Sara Pupi
- Giorgio Chiaverini
- Eduardo Schiavo
- Andrea Tondo

Their work is not visible in this repository's commit log, so it is recorded here instead.
